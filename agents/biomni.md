Biomni is a general-purpose biomedical AI agent developed by [[org:stanford-university]]. Utilizing a single_agent architecture powered by rag and LLM reasoning, the system is designed to autonomously execute research tasks and assist scientists in enhancing productivity.

The platform exposes both a library and a web_ui to facilitate user interaction. Biomni targets research applications across several key areas, including [[domain:drug_discovery]], [[domain:hypothesis_gen]], [[domain:perturbation]], and [[domain:single_cell]] analysis.
