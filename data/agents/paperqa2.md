PaperQA2 is a multi_agent system designed for high-accuracy retrieval augmented generation (rag) across various document formats, including PDFs, text files, and source code. Built by [[org:future-house]], the system is specifically optimized for tasks within the [[domain:literature]], such as question answering, summarization, and contradiction detection.

The system is available as both a cli and a library, allowing users to integrate its capabilities into diverse workflows. It supports advanced features like metadata extraction, citation management, and full-text indexing to facilitate precise information retrieval from scientific documents.
