Robin is a multi_agent system built by [[org:future-house]] and [[org:apurvsinghgautam]] designed to automate the scientific process. By integrating literature search and data analysis agents, the system targets [[domain:scientific_discovery]], [[domain:literature]], and [[domain:drug_discovery]]. It facilitates an iterative lab-in-the-loop framework capable of generating hypotheses, proposing experiments, and interpreting results, as demonstrated by its identification of a novel therapeutic candidate for dry age-related macular degeneration.

The system features a modular architecture that exposes a notebook and a web_ui for user interaction. It supports various LLM backends and provides tools for custom reporting and investigation management.
