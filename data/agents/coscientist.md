Coscientist is an autonomous artificial intelligence system designed to accelerate [[domain:scientific_discovery]] through the integration of large language models. Built by [[org:gomesgroup]], the system utilizes a multi_agent architecture to autonomously design, plan, and execute complex chemical experiments.

The system functions as a library that incorporates tools for internet and documentation search, code execution, and experimental automation. Coscientist has demonstrated its efficacy in tasks such as reaction optimization for palladium-catalysed cross-couplings, providing a versatile and explainable framework for research.
