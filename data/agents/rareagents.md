RareAgents is an autonomous multi-agent system designed to support clinical decision-making for rare diseases. By integrating multidisciplinary team coordination, memory mechanisms, and specialized medical tools, the system addresses the diagnostic and treatment complexities inherent in rare conditions.

Powered by Llama-3.1-8B/70B, the framework is specifically engineered to improve performance in [[domain:clinical_qa]] tasks compared to existing agent frameworks and general-purpose models. The system is accessible via a web_ui and is supported by the MIMIC-IV-Ext-Rare dataset to facilitate ongoing research.
