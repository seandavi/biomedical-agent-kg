Science-Star is an open-source platform developed by [[org:ustc-ai4science]] designed to facilitate the development and experimentation of scientific AI agents. The system utilizes a multi-agent and rag architecture, incorporating a ReAct engine that supports planning, action, memory, and reflection to assist in [[domain:scientific_discovery]].

The platform exposes a library and a web_ui, providing users with a comprehensive toolbox that includes search, crawl, PDF parsing, and code execution capabilities. Science-Star is evaluated on benchmarks including [[benchmark:hle]] and [[benchmark:gaia]], and it features integrated visualization dashboards for data exploration and result analysis.
