DrugAgent is a multi-agent framework designed to automate machine learning programming within the field of [[domain:drug_discovery]]. By integrating domain-specific expertise and custom tools, the system systematically explores and implements solutions to address complex pharmaceutical research challenges.

The agent functions as a library that manages the end-to-end machine learning pipeline, ranging from data acquisition to model performance evaluation. It has demonstrated practical utility in tasks such as ADMET prediction, where it autonomously selects optimal models to achieve high-accuracy results.
