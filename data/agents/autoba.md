AutoBA is a single_agent system designed to perform fully automated [[domain:multi_omics]] analyses. By leveraging large language models, the agent minimizes user input requirements while generating detailed, step-by-step analytical plans. Its architecture allows for the self-design of processes based on input data variations, ensuring versatility across diverse bioinformatics tasks.

Available as a library, AutoBA supports both online and local LLM backends to prioritize data security and privacy. The system incorporates an automated code repair mechanism to enhance stability during end-to-end execution and maintains adaptability to integrate with emerging bioinformatics tools, distinguishing it from static, predefined pipelines.
