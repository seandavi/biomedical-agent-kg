BioDiscoveryAgent is a multi_agent system built by [[org:stanford-university]] designed to automate the closed-loop design of genetic [[domain:perturbation]] experiments. By integrating an LLM with specialized tools for literature review, gene search, and AI critique, the system facilitates autonomous research workflows.

The agent is available as a library and via a cli, supporting various datasets such as IFNG and IL2. It is intended to assist in the process of [[domain:scientific_discovery]] by enabling researchers to execute and analyze experimental designs through configurable Python scripts.
