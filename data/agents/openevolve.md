OpenEvolve is an open-source multi_agent system designed to transform LLMs into autonomous code optimizers. Built by [[org:algorithmicsuperintelligence]], the platform facilitates the discovery of breakthrough algorithms by enabling parallel evolution across islands, aiming to accelerate the process of [[domain:scientific_discovery]].

The system is available as both a cli and a library, supporting research-grade evaluation pipelines and deterministic reproducibility. It has demonstrated performance in diverse areas, including GPU kernel optimization, mathematical problem-solving, and automated algorithm design across multiple programming languages.
