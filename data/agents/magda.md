MAGDA (Multi-Agent Guideline-Driven Diagnostic Assistance) is a biomedical LLM-agent system built by [[org:magda-io]]. It utilizes a multi-agent architecture to provide specialized support for [[domain:clinical_qa]].

The system is designed to be accessible through both an api and a web_ui, facilitating integration into clinical workflows. By leveraging these interfaces, MAGDA aims to assist in diagnostic processes through its guideline-driven framework.
