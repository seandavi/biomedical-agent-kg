Aviary is a multi_agent gymnasium built by [[org:future-house]] for defining custom language agent reinforcement learning environments. The system provides a library and notebook interface to facilitate the development and testing of agents across various scientific and technical domains.

The platform specifically targets [[domain:literature]] search and [[domain:protein_structure]] tasks. It is evaluated on [[benchmark:lab-bench]] and is designed to integrate with the Language Decision Process framework to support complex agent interactions.
